# Proposal

## Why

阅读器已有本地书库、阅读页面和持久化能力，但在线页只有未接通的搜索与详情框架，用户无法在应用内搜索、阅读并继续阅读网文或轻小说。用户已确认笔趣阁与神凑两站、应用内完整阅读流程及数据保留规则，需要据此接通在线内容，并以真实 Windows 完整链路作为完成标准。

## What Changes

- 在线 tab 只显示“网文”和“轻小说”，分别请求笔趣阁 `https://www.bqg616.cc/`、神凑来源；神凑历史入口为 `http://shencou.com`，实际请求域名在来源验证中确认。只搜索当前 tag，支持书名/作者查询和结果翻页；切换 tag 清空关键词及结果，未搜索时显示引导。
- 应用内详情展示封面、标题、作者、简介及目录；用户无需加入书架即可从任意章节开始阅读。轻小说保留分卷、特典、插图和来源顺序，复用现有小说排版、主题、滚动/分页和书签。
- 详情返回恢复搜索上下文，退出阅读返回进入前页面；阅读位置自动保存，重启恢复。在线全书百分比按章节数量计算，界面不显示“估算”；新增章节不改变实际位置。
- 可选加入书架，不另设收藏功能；在线作品移出书架保留位置、书签和历史。删除历史只隐藏记录；首页最多两条继续阅读摘要包含未加入书架的作品，隐藏历史后对应摘要消失。
- 在线缓存独立限额，默认 1024 MB，可选 256/512/1024/2048/4096 MB；正文、封面、插图共享额度。缓存已读内容，最多预取下一章，超限淘汰较久未使用内容并保护当前章节；离线读取实际缓存。
- 进入作品检查目录更新，支持手动目录刷新及重新获取当前章；已有正文不在阅读中后台替换。目录匹配歧义、请求失败、图片失败及保存失败明确提示，保护旧位置和可用缓存。
- 扩展既有 SQLite 与原生阅读仓库支持在线作品，使用新迁移并保留全部本地作品和位置、书签。只读取免资源站账号登录的公开内容；两站搜索和阅读均通过才算完成。

首版不包含在线漫画、独立收藏、打开原站、粘贴作品链接、排行榜、分类浏览、跨站聚合搜索、整本/批量下载、后台定时检查整个书架、站点账号登录、付费购买、验证码交互和插图放大查看器。

## Capabilities

### New Capabilities

- `online-novel-discovery`：两站固定来源、在线 tag、搜索分页、详情与搜索上下文，以及来源启用和完成门槛。
- `online-novel-reading`：应用内小说与轻小说图文阅读、章节导航、返回路径、位置/书签、百分比及异常恢复。
- `online-reader-library`：可选加入书架、移出保留数据、历史可见性、首页继续阅读和本地书库升级兼容。
- `online-reading-cache`：在线独立缓存限额、已读缓存、单章预取、离线、目录更新、正文重新获取与缓存清理。

### Modified Capabilities

无。当前 `openspec/specs/` 尚无阅读规格，本次使用新增能力增量描述已确认的在线行为，不回填整套本地阅读规格。

## Impact

- 前端：`src/features/reader/` 的 provider、模型、页面、图片及定位逻辑；`src/app/services.tsx`、`src/app/router.tsx`；首页摘要；设置模型、迁移、校验与缓存 UI。
- 平台与原生：`src/platform/http.ts`、`src/platform/reader.ts`、HTTP 契约；Rust reader 命令和缓存；新 SQLite 迁移及 `lib.rs` 注册；HTTP capability 与必要 CSP 配置。
- 测试：新增来源解析、导航、目录匹配、在线缓存/竞争与迁移用例，定向运行现有阅读、设置和受影响 HTTP/Steam 回归；公网、真实桌面、安装版分别验收。
- 工程文档：实施时按更新矩阵同步架构与测试指南，规格与实施证据维护在本变更；不在 `docs/` 新建平行提案。
- 外部依赖：两站网页/内部接口与图片主机。2026-10-09 历史抽样中笔趣阁普通正文请求 403、神凑搜索遇到验证；这些是待复核证据，不是本次接入成功。原生协议、免登录可达性、图片完整下载及使用条件仍需具体验证。
- 兼容性：在线 tab 的旧“全部/小说/漫画”入口被替换；不改变本地书架筛选和本地作品移除语义，不修改既有 0001/0002 迁移，不引入第二个书库数据库。依赖与请求头方案依据来源实测决定，不预设浏览器会话能够替代原生 HTTP。

本变更当前仅准备规划文档，未实现、未执行来源验证或功能验收。任一来源未能完成免账号登录的应用内搜索和阅读时，整体功能仍未完成，不以原站跳转、链接入口或演示数据替代。
